# Geometry Toolkit

A collection of computational geometry algorithms and data structures implemented in C++.

Geometry Toolkit provides interactive tools for working with geometric objects, performing spatial queries, and exploring fundamental computational geometry algorithms.

## Features

The application is organized into four main categories.

### 1. Basic Geometry
- Checking collinearity of three points
- Determining the orientation of three points
- Determining the relative position of three points
- Finding the intersection of two lines

### 2. Segment Operations
- Checking whether two segments intersect
- Finding all pairwise segment intersections
- Computing the intersection point of two segments

### 3. Polygon Operations
- Checking quadrilateral convexity
- Checking polygon simplicity
- Testing whether two polygons intersect
- Finding whether a point lies inside an angle
- Testing whether a point lies inside a polygon

### 4. Geometric Search
- Counting points inside rectangles using a sweep-line algorithm and a Fenwick tree
- Point location in a planar subdivision using horizontal strips and trapezoidal decomposition
- Spatial searching using a two-dimensional k-d tree

## Technologies

- C++
- Standard Template Library (STL)
- Microsoft Visual Studio

## Getting Started

### Requirements

- Windows
- Microsoft Visual Studio 2022 or a compatible C++ compiler
- Support for the C++ standard configured in the project

### Build and Run

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the solution file (`.sln`) in Visual Studio.

3. Select the desired build configuration.

4. Build the solution.

5. Run the application.

## Usage

After launching the application, select a category from the main menu:

1. Basic Geometry
2. Segment Operations
3. Polygon Operations
4. Geometric Search

Then select the desired operation and follow the instructions displayed in the console.

## Project Structure

The project contains implementations of geometric primitives, algorithms, data structures, and a console-based user interface.

## Purpose

This project was developed as a practical exploration of computational geometry. It combines fundamental geometric operations with more advanced algorithms and spatial data structures in a single application.
